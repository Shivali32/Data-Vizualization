# Optional Assignments 10 to 12: Maps Text and Networks

Explore geographic, textual, and network data through three optional visualization assignments.

## How It Works

Assignment 10 uses geographic data and map layers. Assignment 11 examines text and presents a visual summary of words or terms. Assignment 12 visualizes relationships as a network. The notebooks and their exported reports retain their shared folder so that the geographic files and tabular inputs stay beside the analyses.

## Main Tasks

- Assignment 10: inspect geolocated fields and build a map.
- Assignment 11: prepare text and explain the chosen text visualization.
- Assignment 12: define nodes and edges and describe the network display.
