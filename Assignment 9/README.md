The notebook follows a dimensionality-reduction workflow: choose a dataset, select features, prepare the numeric inputs, and compare projected views. Written explanations relate the plotted structure to the source features and labels.

- Apply the reduction methods included in the notebook.
- Compare projected patterns with the original attributes.
