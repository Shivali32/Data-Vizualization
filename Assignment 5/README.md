# Assignment 5: Tidying Billboard Data

Reshape chart-position records from a wide table into a tidy dataset.

## How It Works

The Billboard notebook works with song metadata and weekly rank columns. It uses pandas transformations to put weekly observations into a form suitable for grouped analysis and plotting.

## Main Tasks

- Inspect weekly rank columns and missing values.
- Reshape records into a long representation.
- Summarize and plot the resulting chart histories.
