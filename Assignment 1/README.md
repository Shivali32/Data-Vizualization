# Assignment 1: Everyday Visualizations

Examine examples of data visualization in everyday interfaces and publications.

## How It Works

The scavenger-hunt report identifies the information represented by calendars, music applications, and other visual displays. Each example explains the visual form and the role it plays in communicating data.

## Main Tasks

- Identify the underlying data in each example.
- Describe how position, color, or layout encodes information.
- Explain what the reader can learn from the display.
