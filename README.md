# Data Visualization

This repository contains visualization coursework built from Python notebooks, datasets, chart exports, and written design explanations. The assignments begin with everyday visualization examples and structured solar-system data, then examine perception, misleading charts, and tidy data. Later work compares visual encodings, logarithmic scales, multivariable plots, and dimensionality reduction. Optional exercises cover maps, text, and networks, while the examination material applies visual reasoning to supplied examples and plotted data. Pandas and NumPy support data preparation, with Matplotlib, Seaborn, Altair, and geographic libraries used in the notebook exercises. Source notebooks and their exported reports are kept with the datasets they reference.

## Assignments and Labs

- **[Assignment 1: Everyday Visualizations](Assignment%201/)**  
  Examine examples of data visualization in everyday interfaces and publications.

- **[Assignment 2: Solar System Data](Assignment%202/)**  
  Explore solar-system records with Python, NumPy, and pandas.

- **[Assignment 3: Perception and Statistical Summaries](Assignment%203/)**  
  Compare visual perception experiments with datasets that share similar statistical summaries.

- **[Assignment 4: Correcting Misleading Charts](Assignment%204/)**  
  Analyze misleading graphics and construct clearer alternatives.

- **[Assignment 5: Tidying Billboard Data](Assignment%205/)**  
  Reshape chart-position records from a wide table into a tidy dataset.

- **[Assignment 6: Visual Encoding](Assignment%206/)**  
  Explore one-dimensional plots and encode several movie or car attributes in a chart.

- **[Assignment 7: Logarithmic Scales](Assignment%207/)**  
  Examine when logarithmic axes help communicate data across large numeric ranges.

- **[Assignment 8: Multivariable Visualization](Assignment%208/)**  
  Explore relationships across several dataset features using plots beyond a single dimension.

- **[Assignment 9: Dimensionality Reduction](Assignment%209/)**  
  Explore lower-dimensional views of data with multiple numeric features.

- **[Assignments 10 to 12: Maps Text and Networks](Optional%20Assignments/)**  
  Optional notebook exercises for geographic layers, text displays, and network relationships.

- **[Final Examination](Final%20Exam/)**  
  Written responses and a notebook for examination plots.
