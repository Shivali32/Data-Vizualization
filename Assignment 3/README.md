# Assignment 3: Perception and Statistical Summaries

Compare visual perception experiments with datasets that share similar statistical summaries.

## How It Works

The perception notebook explores Stevens power law, while the Anscombe-related notebooks illustrate why plotted distributions can reveal patterns that summary statistics hide. The CSV files provide the observations used by the examples.

## Main Tasks

- Inspect the measurement data and summary values.
- Plot relationships and compare their shapes.
- Explain perception effects and differences between statistics and visual evidence.
