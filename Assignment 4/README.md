# Assignment 4: Correcting Misleading Charts

Analyze misleading graphics and construct clearer alternatives.

## How It Works

The reports discuss grocery-spending and geographic examples, and the graph notebook builds replacement plots. Additional text-processing exercises and story datasets accompany the chart work.

## Main Tasks

- Identify the encoding or scale that causes confusion.
- Choose a chart that matches the comparison being made.
- Explain the corrected design with reference to the original graphics.
