# Assignment 6: Visual Encoding

Explore one-dimensional plots and encode several movie or car attributes in a chart.

## How It Works

The 6A notebook compares distribution plots using Matplotlib, Seaborn, and Altair. The 6B notebooks map attributes of movie records onto visual properties and contrast simple, cluttered, and focused chart designs.

## Main Tasks

- Read the car or movie JSON records.
- Compare distribution plots and combinations of visual encodings.
- Explain how selected encodings affect readability.
