# Assignment 2: Solar System Data

Explore solar-system records with Python, NumPy, and pandas.

## How It Works

The notebook reads the supplied JSON data, inspects fields, and answers questions about celestial bodies. The exercise uses filtering and numeric summaries to connect structured records with exploratory analysis.

## Main Tasks

- Load and inspect the JSON records.
- Filter or summarize properties of solar-system bodies.
- Explain the results in notebook text and exported output.
