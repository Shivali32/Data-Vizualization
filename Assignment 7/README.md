# Assignment 7: Logarithmic Scales

Examine when logarithmic axes help communicate data across large numeric ranges.

## How It Works

The submitted PDF contains the notebook exercise, plots, and written explanations about scale selection. The task compares how visual interpretation changes when an axis represents ratios rather than equal additive differences.

## Main Tasks

- Identify values spanning several orders of magnitude.
- Compare linear and logarithmic presentations.
- Explain the effect of axis choice on interpretation.
